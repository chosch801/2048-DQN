# 2048 强化学习算法研究 (基于 Transformer 与 Double DQN)

本项目采用强化学习技术训练 2048 游戏智能体。结合无模型（Model-Free）的 Double DQN 算法与 Transformer 状态表征提取器，旨在探索自监督辅助学习与复杂奖励塑造（Reward Shaping）在离散动作空间中的实际表现与策略演化过程。

## 1. 网络架构设计 (Model Architecture)

传统 2048 强化学习多采用卷积神经网络（CNN）或多层感知机（MLP），本项目引入了轻量级 Transformer 作为特征提取主干：
- **状态表征**：对 4x4 盘面上提取到的数值先进行 log2 预处理，降低指数级数值带来的方差，映射为 16 维序列输入。
- **二维位置编码 (2D Positional Encoding)**：结合 2048 棋盘的物理拓扑结构，分别对行和列进行嵌入，拼接为联合位置编码，从而帮助模型建立网格空间感。
- **核心提取器**：配置 d_model=64，2 层 2 头的精简 Transformer Encoder。使用全局平均池化（Global Average Pooling）替代 Flatten 操作，有效缩减全连接层参数并提升泛化稳定性。
- **双头输出设计 (Dual Heads)**：
  - **DQN 决策头**：输出状态对应的 4 个动作的 Q 值评估。
  - **自监督学习辅助头 (SSL Head)**：通过预测执行动作后的“下一步盘面状态 (Next-State)”，辅助主干网络更快理解 2048 游戏“碰撞相加与新方块生成”的物理机制，加速早期训练收敛。

## 2. 奖励机制设计 (Reward Shaping)

针对 2048 游戏原生分数的稀疏性与后期指数级膨胀问题，本项目在环境交互 (`env.py`) 中设计了较为复杂的奖励函数引导：
- **平方根缩放 (Square Root Scaling)**：将合并得分由原始的 R 转换为 sqrt(R)/2.0。既保证了对高级方块合并的激励区分，又避免了后期梯度爆炸。
- **单调性约束 (Monotonicity Penalty)**：借鉴人类高阶玩家的“蛇形排布”经验，通过对行、列作差分运算，计算并非单向递增/递减导致的“单调性散失度”并施加惩罚，引导棋盘结构有序化。
- **角落锁定激励 (Corner Bonus)**：针对盘面最大值方块，若其处于四个角落之一，则给予动态权重加分，强制培养智能体的防御性靠边站位习惯。
- **辅助小项**：包括空格保留奖励（维持生存空间）与相邻等值数字的合并潜力（Merge Potential）奖励。

## 3. 训练配置与工程优化

- **优化与损失函数**：采用 Double DQN 配合 `SmoothL1Loss`（Huber Loss），有效缓解传统 DQN 常见的 Q 价值高估问题。优化器使用 Adam。
- **无偏经验回放 (Replay Buffer)**：维护 10 万级的经验池 (`np.savez_compressed` 序列化存储)。放弃了可能带来分布偏移的优先经验回放，转而使用纯均匀随机采样，保证独立同分布特性。
- **全状态断点续训**：训练脚本完整序列化模型权重、优化器动量、经验池数据以及 epsilon 衰减进度，做到无损的中断与恢复接力训练。

## 4. 实验结果与局限性分析

经过三万余局的训练观察，目前该模型已掌握较好的基础策略（如“大数定角”与“单调递减排列”），能够高频且**稳定地合成 256 与 512 方块**。
但在向 1024 推进时目前出现了明显的瓶颈。**需要明确这并非 DQN 算法能力达到上限**，而是由于我们现有的简单奖励规则与探索机制导致策略陷入了**深度的局部最优**：
1. **探索机制固化**：当前采用单向的贪心指数衰减策略，探索率衰减到底部（0.1）后维持不变。这导致智能体在掌握 512 策略后完全丧失了寻找新方案的动力，无法尝试存在短期风险但有利于长远布局的操作。
2. **保守的规则阻碍破局**：为了使模型快速入门而设置的“单调性惩罚”与“角落锁定”，在游戏后期反而形成了约束。合成 1024 往往需要在空间极度拥挤的情况下做出短暂的“破坏性移动”（如牺牲局部的单调性或大数字移出角落）。由于当前的反馈机制缺乏动态调节（即尚未引入 Curriculum Reward 课程奖励机制），这些短视的高昂惩罚让模型因“不敢犯错”而无从破局。

**后续展望**：未来只需引入微小的变动即有极大潜力打破僵局。通过实施**探索重置机制 (Warm Restarts)**（大周期拉高探索率以打破定势），或**对单调性惩罚规则进行后期阶段性的平滑宽减**，均有望使模型跃升至全新水平。

## 5. 项目运行指南

**环境依赖**
```bash
pip install numpy torch matplotlib
```

**目录结构与执行**
- `game_2048.py`: 2048 游戏本体与矩阵运算逻辑
- `env.py`: 强化学习 Gym 接口封装与所有奖励函数的运算逻辑
- `model.py`: Transformer-DQN 网络结构定义
- `replay_buffer.py`: 回放队列存储与断点快照存取
- `train.py`: 训练循环主程序

**启动训练**
```bash
python train.py
```
